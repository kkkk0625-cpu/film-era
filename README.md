# 菲林纪元 · Film Era

一个关于胶片摄影文化的静态网站，面向胶片新手与爱好者，用**知识 + 社区 + 工具**三条线组织内容。
独立完成从竞品调研、信息架构设计到前端实现的全过程。

## 内容结构

| 模块 | 目录 | 解决的问题 |
|---|---|---|
| 首页 | `/` | 用一条「认识 → 选购 → 拍摄 → 冲扫 → 分享」的路径做导览 |
| 胶片史长廊 | `history/` | 按时间轴梳理胶片技术与文化史，解决科普碎片化 |
| 知识仓储 | `lab/` | 曝光、冲洗、扫描等基础知识的系统整理 |
| 胶片与器材库 | `pu/` | 40+ 款在产/停产胶卷按品牌、ISO、色调分类索引 |
| 资讯 | `news/` | 行业动态与新品消息聚合 |
| 社区 | `community/` | 作品与经验的分享、征集 |
| 关于 | `about/` | 项目缘起与制作说明 |

## 设计思路

调研了图虫、VSCO、Analog Cafe、Film Photography Project 等同类站点，发现它们普遍偏重
**器材交易与作品展示**，缺少成体系的胶片文化科普。本项目据此把「知识」放在第一位，
用统一的视觉语言（暗房红、胶片齿孔、打字机字体）承载内容。

## 技术

纯静态站点，HTML + CSS + 原生 JavaScript，无构建步骤、无框架依赖。
页面交互用原生 DOM 实现，图片素材经压缩优化后托管在 GitHub Pages。

## 本地预览

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```
